# Worldbank Logistic Regression — Логістична регресія на даних World Bank

Навчальний проєкт для студентів. Показує:

- як налаштувати сучасне Python-середовище за допомогою **uv**;
- як працювати з проєктом у **VSCode**;
- як побудувати модель **логістичної регресії** на реальних даних World Bank.

**Дослідницьке питання:** чи можемо ми за економічними показниками країни
передбачити високий рівень користування інтернетом?

## Частина 1. Встановлення та запуск (крок за кроком)

Спочатку має бути встановлений git — завантаж із https://git-scm.com/download/win
(або, якщо є `winget`: `winget install Git.Git`). Потім:

```powershell
git clone https://github.com/crowbar4ik/worldbank-logistic-regression.git
cd worldbank-logistic-regression
```

**Спосіб Б. Просто скачати ZIP** (найпростіше, git не потрібен).

2. Натисни зелену кнопку **Code** → **Download ZIP**.
3. Розпакуй архів у зручну папку.

### Крок 1. Встановити VSCode

1. Відкрий https://code.visualstudio.com/ і завантаж версію для своєї ОС.
2. Встанови й запусти VSCode.
3. Встанови розширення **Python** (від Microsoft):
   - відкрий панель Extensions (`Ctrl+Shift+X`);
   - у пошуку введи `Python`;
   - встанови розширення з назвою **Python** (видавець Microsoft).

### Крок 2. Встановити uv

`uv` — це швидкий менеджер пакетів і середовищ для Python (заміна pip + venv).

**Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS / Linux:**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Перевір, що встановилось (можливо, треба перезапустити термінал):

```powershell
uv --version
```

Докладніше: https://docs.astral.sh/uv/getting-started/installation/

### Крок 3. Відкрити проєкт у VSCode

1. `File` → `Open Folder...`
2. Обери папку `worldbank-logistic-regression` (та, яку ти отримав у Кроці 0).

> **Важливо:** усі команди з наступних кроків (`uv ...`) запускай у
> **вбудованому терміналі VSCode**. Відкрий його через `Terminal` → `New Terminal`
> (або `Ctrl+~`). Так термінал уже буде в папці проєкту — саме там, де треба.

### Крок 4. Встановити Python потрібної версії

Проєкт вимагає Python 3.12 (записано у `.python-version`). uv сам завантажить

1. Натисни `Ctrl+Shift+P` → `Python: Select Interpreter`.

## Частина 2. Огляд алгоритму логістичної регресії

### Постановка задачі

Ми хочемо передбачити **бінарну** ознаку: чи є в країні високий рівень
користування інтернетом (`high_internet`).

- `high_internet = 1` — інтернетом користуються **щонайменше 70%** населення;
- `high_internet = 0` — менше 70%.

Це задача **бінарної класифікації**. Саме тому використовуємо логістичну
регресію, а не звичайну лінійну.

### Ознаки (предиктори)

Модель робить прогноз на основі трьох економічних показників країни:

| Ознака               | Що означає                          |
|----------------------|-------------------------------------|
| `gdp_per_capita`     | ВВП на душу населення (за ПКС)       |
| `urban_population`   | Частка міського населення, %         |
| `electricity_access` | Доступ до електроенергії, %          |

> Показник `internet` (%) використовується лише для формування цільової
> змінної, а не як ознака — інакше модель просто «підглядала» б відповідь.

### Як працює логістична регресія

1. **Лінійна комбінація.** Модель обчислює зважену суму ознак:

   ```
   z = b0 + b1·gdp + b2·urban + b3·electricity
   ```

   де `b0` — вільний член (intercept), `b1..b3` — коефіцієнти при ознаках.

2. **Сигмоїда.** Значення `z` (будь-яке число) стискається у ймовірність
   від 0 до 1 за допомогою логістичної (сигмоїдної) функції:

   ```
   p = 1 / (1 + e^(-z))
   ```

   Це і є ймовірність того, що `high_internet = 1`.

3. **Поріг рішення.** Якщо `p >= 0.5` — прогноз `1`, інакше `0`.

4. **Навчання.** Під час `model.fit(...)` алгоритм підбирає коефіцієнти
   `b0..b3` так, щоб прогнозовані ймовірності якнайкраще збігалися з реальними
   мітками на навчальних даних.

### Етапи в коді

Скрипт `logistic_regression.py` проходить такі кроки:

1. **Зчитування даних** з `worldbank.xlsx` (аркуш `Data`).
2. **Відбір показників** — лишаємо лише 4 потрібні індикатори World Bank.
3. **Перетворення на числа** — нечислові значення (`..`) стають `NaN`.
4. **Pivot** — з «довгого» формату в «широкий»: кожна країна = один рядок.
5. **Видалення агрегатів** — прибираємо «Світ», «ЄС», регіони тощо,
   лишаємо лише реальні країни (перевірка через `pycountry`).
6. **Очищення пропусків** — видаляємо рядки без потрібних значень.
7. **Цільова змінна** `high_internet` за порогом 70%.
8. **Перевірка кореляції** між ознаками (щоб вони не дублювали одна одну).
9. **Розподіл train / test** (80% / 20%) зі збереженням часток класів
   (`stratify`).
10. **Стандартизація** ознак через `StandardScaler` — приводимо різні масштаби
    (ВВП у тисячах, відсотки до 100) до порівнянного вигляду.
    Важливо: `fit` робиться **лише** на train-даних.
11. **Навчання** логістичної регресії.
12. **Оцінка якості:** accuracy, confusion matrix, precision / recall / F1.
13. **Аналіз результатів:** прогнози по країнах, помилки моделі, приклад України.

### Як читати результати

- **Accuracy** — частка правильних прогнозів.
- **Confusion matrix** — таблиця TN / FP / FN / TP: де модель вгадала, а де ні.
- **Coefficients** — оскільки ознаки стандартизовані, за величиною коефіцієнта
  видно, який показник найсильніше впливає на прогноз (знак — напрямок впливу).
- **Model mistakes** — країни біля порогу 70% (як-от Туніс чи Гаяна), де модель
  найчастіше помиляється, бо вони «на межі».
